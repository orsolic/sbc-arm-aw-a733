# SBC ARM Allwinner A733
Experiments done on [Radxa A7Z board](https://docs.radxa.com/en/cubie/a7z)

## Intro
After some not great things with [H618](https://wiki.sipeed.com/hardware/en/longan/h618/lpi3h/1_intro.html) (and [A20](http://www.cubietech.com/product-detail/cubieboard2/) from 2013) I told my self that I would never buy Allwinner again, bought relatively expensive RK3568 board, and...  
Bought 1GB model for playing around in March 2026 for 30€, 7 months later it is 45€, and that's probably without new EU tax...  
Or, how Radxa [said](https://x.com/RadxaComputer/status/1959829465460252857) it is $15 for 1GB model...  

It is not SoM, but it is small, low profile, and contains 2xA76 (much faster than A55s on RK3568).  
Plans are to thinker with it, enable as much as usable "desktop"/workshop Linux/BSD machine, on ZFS, of course!  

## Specs
- Allwinner A733 CPU with 2x ARM Cortex A76
- 1-16 GB LPDDR4
- USB-C DP
- micro HDMI
- USB WLAN (around 100 MBit/s down & up)
- USB-C 2.0 or pin header for 5V power
- PCIe 3.0 x1
